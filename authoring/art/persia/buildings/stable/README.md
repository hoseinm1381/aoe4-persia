# Persian Stable — unbuilt source draft

Only the staged source recipe and editing directions exist. No Blender execution, saved `.blend`, atlas generation, checked geometry, states, LODs, native cook or integration is claimed.

The original animal plan uses a narrow west-side range with three generous east-facing stall openings, high back-wall ventilation, low internal partitions, a separate northern tack room and an open handling/tether court. A2 has a low timber/clay roof and vaulted tack room. A3 adds three shallow barrel roofs, divided feed storage and a handling shade. A4 formalizes the animal range and adds a modest occupied supervisor room with a real split-wall window. Changes use the existing A2/A3/A4 bodies only; no early stable tier is invented. Animal-scale openings and generous working negative space distinguish this plan from a lodging barracks.
